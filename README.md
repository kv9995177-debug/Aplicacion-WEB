🧩 Aplicación Web Funcional

Este proyecto es una aplicación web completa que incluye un backend desarrollado con Node.js, Express y MongoDB, junto con un frontend construido en React utilizando JavaScript.
Ambas partes trabajan de manera conjunta para ofrecer una solución funcional, modular y escalable.

🚀 Tecnologías utilizadas
Backend:

  Node.js
  
  Express
  
  MongoDB (mediante Mongoose)

Frontend (Puerto 3001):

  React
    
  JavaScript
    
  Create React App 


▶️ Ejecución del proyecto

🖥️ Backend:
📌 Instalación
    cd backend
    npm install

▶️ Ejecutar
  npm run dev


🌐 Frontend:
📌 Instalación
  cd frontend
  npm install


▶️ Ejecutar:
  npm start


🔗 Comunicación entre frontend, backend y base de datos

El frontend se comunica con el backend enviando peticiones HTTP a http://localhost:3000.

El backend se conecta a MongoDB 

Asegúrate de que:

MongoDB esté corriendo.
